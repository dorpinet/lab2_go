Практична робота № 2: **Сокетне програмування та обмін повідомленнями по TCP/UDP**.
 
Консольний TCP-сервер диспетчеризації, який одночасно обслуговує багато клієнтів за моделлю «горутина на кожне з'єднання», підтримує текстовий протокол команд і широкомовну розсилку повідомлень між учасниками.
 
## Запуск
 
Потрібен **Go 1.22+**.
 
```bash
git clone https://github.com/dorpinet/lab2_go.git
cd lab2_go
go run .
```
 
Запуск із перевіркою на стан гонитви (на Windows потрібен gcc):
 
```bash
go run -race .
```
 
Підключення клієнтів (кожен у своєму терміналі):
 
```bash
telnet localhost 9000
```
 
або `ncat localhost 9000`.
 
## Реалізовані рівні
 
### Рівень 1. Багатопотоковий TCP-сервер команд
 
- TCP-слухач на порту `9000`, цикл `Accept()`;
- кожне з'єднання обслуговується в окремій горутині;
- построкове читання через `bufio.NewReader` і очищення через `strings.TrimSpace`;
- команди `ECHO`, `TIME`, `CLOSE`, `QUIT` та обробка невідомих команд;
- перевірено одночасне підключення двох клієнтів.

### Рівень 2. Потокобезпечна реєстрація та Broadcast
 
- `Registry` зберігає активні з'єднання в `map` під захистом `sync.RWMutex`;
- клієнт додається після підключення й гарантовано видаляється через `defer`;
- команди `BROADCAST` / `MSG` розсилають повідомлення всім, крім відправника;
- усі учасники отримують системні сповіщення про приєднання та вихід клієнта;
- сервер запущено через `go run -race .`, попереджень `WARNING: DATA RACE` немає.
